# 오늘 실행해본 코드 중 가장 흥미로웠던 것
랜덤으로 실행을 하고 생성했던 cellular_cave 파일이 가장 흥미로웠다.
왜냐하면 도트로 찍혀있던 공간이 점점 동굴에 가까운 형태로 깎여나가는 부분이 신기하다고 느꼈기 때문이다.
# 파라미터를 바꿨을 때 어떤 변화가 있었는지
맵 생성 시, 이를 (0.45) +-0.3씩 하니 동굴 초기 값이 도트 수가 더 많아지거나 적어졌다. 또한, 다듬기 과정에서 오히려 동굴처럼 생성되지 않았다.
# 기말 프로젝트에서 프로시저럴 생성을 활용할 수 있을지
스테이지 클리어 형식을 모든 스테이지를 설계하기에는 힘들기에, 시드 값을 정해둔 스테이지를 제작을 하는 형식으로 활용 가능하도록 할 예정이다.
